# Design patterns în Java

Colecție de exerciții cu design patterns structurale și comportamentale. Fiecare pachet are propria clasă `Main`.

| Pachet | Pattern | Exemplu |
|---|---|---|
| `adapterPlata` | Adapter | Integrarea unui gateway de plată vechi într-un serviciu de checkout |
| `patterns.ex1.composite` | Composite | Virus, tulpini, țări și continente |
| `patterns.ex1.proxy` | Proxy | Controlul accesului vizitatorilor într-un spital |
| `patterns.ex2.flyweight` | Flyweight | Rețete și recomandări de sănătate reutilizate |
| `patterns.ex2.template` | Template Method | Preluarea urgențelor în spitale publice și private |
| `patterns.ex3.chainOfResponsability` | Chain of Responsibility | Filtrarea elementelor unei pagini web |
| `patterns.ex3.strategy` | Strategy | Moduri de vizualizare a produselor dintr-un magazin |
| `patterns.ex4.composite` | Composite | Meniul zilnic organizat pe categorii |
| `patterns.ex4.decorator` | Decorator | Produse cu variante (italienesc, spaniol) |
| `patterns.ex5.proxy` | Proxy | Acces limitat la un spital |
| `patterns.ex6.composite` | Composite | Rezultatele unui referendum: secții, județe, nivel național |
| `patterns.ex6.template` | Template Method | Votarea în țară și în străinătate |
| `patterns.ex7.composite` | Composite | Categorii de produse |
| `patterns.ex7.decorator` | Decorator | Magazin cu discount |
| `patterns.ex8.observer` | Observer | Notificarea clienților despre reduceri prin e-mail și telefon |
| `patterns.ex8.strategy` | Strategy | Plata comenzii cu cardul sau prin virament |
| `patterns.ex9.proxy1` | Proxy | Autentificare securizată la un magazin |
| `patterns.ex10.chainOfResponsability` | Chain of Responsibility | Filtrarea produselor după brand, culoare și mărime |
| `patterns.ex10.strategy` | Strategy | Parametrizarea căutării unui client |
| `patterns.ex11.chainOfResponsability` | Chain of Responsibility | Bancomat care eliberează bancnote de 50, 20 și 10 |
| `patterns.ex11.strategy` | Strategy | Strategii de retragere a numerarului |

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează clasa `Main` din pachetul dorit.
